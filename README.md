# 🏏 India vs West Indies – 1st ODI 2026 | Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Power BI Cricket Match Analysis Dashboard** created to analyze player and team performance from the **India vs West Indies 1st ODI 2026**.

The dashboard provides a clear view of batting, bowling, boundaries, wickets, and overall match performance using interactive Power BI visuals and KPIs.

---

## 🎯 Project Objectives

- Analyze player batting performance
- Identify the **Top 5 Run Scorers**
- Identify the **Top 5 Six-Hitters**
- Identify the **Top 5 Wicket Takers**
- Compare fours and sixes between both teams
- Display the **Match Winner**
- Compare team-level performance
- Create an interactive and visually appealing cricket dashboard
